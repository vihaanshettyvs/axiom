# ORBITA — Orbital Triage and Disaster Response

A software simulation demonstrating coordinated satellite sensing,
orbital asset triage, disaster monitoring, and satellite servicing.

## Project Structure

- sensing/  — Telemetry, data compression, positioning and hazard sensing
- data/     — Historical wildfire datasets and simulation data
- tests/    — Automated tests

## Development

Python-based simulation prototype.

Real historical datasets and simulated telemetry will be clearly
distinguished in the demonstration.
